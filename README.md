# Audio Panel with Tooltip

Omarchy audio panel with a hover tooltip showing the current output device.

A modified copy of the built-in `omarchy.audio` plugin from [Omarchy](https://github.com/basecamp/omarchy) (MIT). It replaces the stock plugin when enabled; `omarchy plugin remove io.github.rk4500.audio-tooltip` restores it.

Install: `omarchy plugin add <this repo's git URL> --enable`

Personal config, shared as-is: no support or compatibility promises.
